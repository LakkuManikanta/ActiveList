# ActiveList 
    ActiveList is a simple React based application. it displays a list of users and show their current status (Active or Inactive).
    
The app is fast, responsive and easy to customize.
ActiveList build using **Vite** (lightning-fast development) and **Tailwind css** (modern styling).

# Features
  1. Display a list of users with active/inactive status.
  2. Active users are highlighted in green.
  3. Inactive usera are hihglighted in red.
  4. Built with Vite for super-fast loading.
  5. Tailwind CSS for responsive and modern Style.
